# boardgame-scorer-site

Pages publiques de l'application Android **BoardGame Scorer** : la page de
présentation et la politique de confidentialité exigée par le Play Store.

Ce dépôt est public parce que GitHub Pages n'est pas disponible sur un dépôt
privé avec un compte gratuit, et que l'URL de la politique doit être accessible
à tous. **Le code de l'application est ailleurs, dans un dépôt privé.** Rien ici
ne doit contenir autre chose que ces pages.

| Page | Adresse |
|---|---|
| Présentation | https://ydexmier.github.io/boardgame-scorer-site/ |
| Confidentialité | https://ydexmier.github.io/boardgame-scorer-site/confidentialite.html |

L'adresse de la politique est celle déclarée au Play Store : **ne pas renommer
`confidentialite.html`.**

Le texte de référence de la politique vit dans le dépôt de l'application
(`docs/04-business/privacy-policy.md`). Toute modification s'y fait d'abord,
puis se reporte ici.
